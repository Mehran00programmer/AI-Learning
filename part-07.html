01

مسئله ارضای محدودیت (CSP)

انتشار قید (constraint propagation) یعنی تعیین اینکه قیدها و مقادیر ممکن یک متغیر چگونه بر مقادیر ممکن متغیرهای دیگر اثر می‌گذارند؛ شکلی از استدلال «کمترین تعهد». مثلاً در ۸-وزیر هر وزیر خانه‌های تحت حمله را حذف می‌کند و جای وزیر بعدی را در سطر/ستونی با کمترین خانه سالم می‌گذاریم.

تعریف CSP

مجموعه متغیرها X₁…Xₙ، دامنه Dᵢ برای هر متغیر (معمولاً متناهی) و مجموعه قیدها C₁…C_p که هر کدام ترکیب‌های مجاز مقادیر زیرمجموعه‌ای از متغیرها را مشخص می‌کنند. هدف: مقداردهی به همه متغیرها به‌طوری‌که همه قیدها برقرار باشند.

02

مثال‌های CSP

مسئلهمتغیرها و دامنهقیدها
رنگ‌آمیزی نقشه۷ متغیر WA,NT,SA,Q,NSW,V,T با دامنه red,green,blueدو ناحیه مجاور رنگ یکسان نداشته باشند
۸-وزیرX₁…X₈ با دامنه 1…8قیدهای دوتایی سطر، ستون و قطر
معمای خیابان (zebra)نام، رنگ، نوشیدنی، شغل و حیوان هر ۵ خانهقیدهای یگانی (N₁ = Norwegian)، دوتایی و همه‌متفاوت
زمان‌بندی کارهاکارها T1…T4قیدهای زمانی مثل «T1 در طول T3»
3-SATn متغیر بولیp بند سه‌تایی؛ مسئله NP-کامل

در finite CSP دامنه متناهی است؛ برنامه‌ریزی خطی روی اعداد حقیقی مثالی از infinite CSP است. در این درس فقط حالت متناهی بررسی می‌شود.

03

CSP به‌عنوان جستجو و خاصیت جابه‌جایی

به‌صورت مسئله جستجو: حالت = مقداردهی معتبر جزئی، حالت اولیه = مقداردهی خالی، جانشین = افزودن یک مقداردهی، آزمون هدف = k = n. اگر دامنه‌ها اندازه d داشته باشند، O(dⁿ) مقداردهی کامل وجود دارد.

جابه‌جایی (commutativity)

ترتیب مقداردهی به متغیرها بر مقداردهی‌های کامل معتبر اثری ندارد. پس می‌توان در هر گره فقط یک متغیر را انتخاب و همه مقادیرش را امتحان کرد: ضریب انشعاب از r·s به s کاهش می‌یابد و عمق راه‌حل همان n می‌ماند. همچنین نیازی به نگه‌داشتن مسیر نیست.

04

الگوریتم Backtracking

Backtracking ساده‌شده DFS به‌صورت بازگشتی است.

Pseudocode — CSP-BACKTRACKING 
CSP-BACKTRACKING(A)
1. If assignment A is complete then return A
2. X <- select a variable not in A
3. D <- select an ordering on the domain of X
4. For each value v in D do
   a. Add (X <- v) to A
   b. If A is valid then
        result <- CSP-BACKTRACKING(A)
        If result != failure then return result
   c. Remove (X <- v) from A
5. Return failure

کارایی به دو پرسش بستگی دارد: کدام متغیر بعدی باشد (برای زودتر فهمیدن تناقض) و مقادیر آن به چه ترتیبی امتحان شوند (برای زودتر یافتن راه‌حل).

05

Forward Checking

هر وقت جفت X ← v به A اضافه شد، برای هر متغیر مقداردهی‌نشده Y که با متغیرهای A قید دارد، مقادیری از دامنه Y که قید را نقض می‌کنند حذف می‌شود. اگر دامنه‌ای تهی شود، مقداردهی فعلی به راه‌حل نمی‌رسد. هزینه: O(nsd) (s بیشترین تعداد قیدهای یک متغیر).

مثال رنگ‌آمیزی: پس از WA=R، Q=G، V=B دامنه SA تهی می‌شود. اما FC همه تناقض‌ها را نمی‌بیند (مثلاً NT و SA هر دو فقط B دارند و مجاورند)؛ برای این به انتشار قوی‌تر نیاز است.

06

هیوریستیک‌های انتخاب متغیر و مقدار

هیوریستیکقاعدهدلیل
Most-constrained-variable (MRV)متغیری با کوچک‌ترین دامنه باقی‌ماندهکاهش ضریب انشعاب
Most-constraining-variableدر تساوی MRV، متغیری که در بیشترین قید با متغیرهای مقداردهی‌نشده است (مثلاً SA)افزایش حذف مقادیر آینده
Least-constraining-valueمقداری که کمترین مقدار را از دامنه متغیرهای دیگر حذف می‌کندبیشترین احتمال عدم تناقض (نیازمند FC برای هر مقدار)
نکته

همه متغیرها باید مقدار بگیرند، اما برای هر متغیر فقط یک مقدار لازم است؛ برای همین ترتیب انتخاب متغیر و مقدار قاعده‌های متفاوت دارند.

07

الگوریتم AC3

AC3 سازگاری کمان را برای قیدهای دوتایی برقرار می‌کند.

Pseudocode — AC3 
REMOVE-VALUES(X, Y)
1. removed <- false
2. For every value v in the domain of Y do
     If there is no value u in the domain of X such that
     the constraint on (X,Y) is satisfied then
        remove v from Y's domain; removed <- true
3. Return removed

AC3
1. Initialize queue Q with all (not yet instantiated) variables
2. While Q is not empty do
   a. X <- Remove(Q)
   b. For every (not yet instantiated) Y related to X by a binary constraint
        If REMOVE-VALUES(X, Y) then
           if Y's domain is empty then exit
           Insert(Y, Q)
  • هر متغیر حداکثر d بار وارد صف می‌شود و REMOVE-VALUES هزینه O(d²) دارد؛ پس AC3 هزینه O(nsd³) دارد (گران‌تر از FC)
  • AC3 همه تناقض‌ها را پیدا نمی‌کند: سه متغیر با دامنه {1,2} و قیدهای X≠Y, X≠Z, Y≠Z ناسازگارند ولی AC3 چیزی حذف نمی‌کند
  • قیدهای غیردوتایی هم نیازمند تعمیم‌اند

در ۴-وزیر: پس از قرار دادن X₁=1 و FC، AC3 مقدارهایی از X₂ و X₃ حذف می‌کند تا دامنه X₃ تهی می‌شود؛ یعنی پس‌گرد زودهنگام.

08

ترکیب Backtracking و انتشار قید

وقتی اکثر قیدها دوتایی‌اند، ترکیب Backtracking با FC و/یا AC3 معمولاً مصالحه خوبی بین زمان جستجو و زمان انتشار است.

Pseudocode — Backtracking + AC3 + FC 
CSP-BACKTRACKING(A, var-domains)
1. If A is complete then return A
2. Run AC3 and update var-domains
3. If a variable has an empty domain then return failure
4. X <- select a variable not in A     // MRV, degree
5. D <- select an ordering of X's domain  // LCV
6. For each value v in D do
   a. Add (X <- v) to A
   b. var-domains <- forward-checking(var-domains, X, v, A)
   c. If no variable has an empty domain then
        result <- CSP-BACKTRACKING(A, var-domains)
        If result != failure then return result
   d. Remove (X <- v) from A
7. Return failure
09

بهره‌گیری از ساختار CSP

  • اگر گراف قید چند مؤلفه دارد، برای هر مؤلفه یک CSP مستقل حل کنید (مثلاً T در نقشه استرالیا)
  • اگر گراف قید یک درخت است: متغیرها را از ریشه به برگ مرتب کنید، برای j = n … 2 REMOVE-VALUES(Xⱼ, parent) را اجرا کنید، سپس به X₁ هر مقدار معتبر بدهید و به ترتیب به هر فرزند مقداری سازگار با والد بدهید (بدون پس‌گرد)
  • در هر مقداردهی، متغیر مقداردار را از گراف حذف کنید؛ اگر گراف درخت شد، همان روش درخت

کاربردها

برنامه‌ریزی خدمه پرواز، مدیریت ناوگان حمل‌ونقل، زمان‌بندی قطار و پرواز، زمان‌بندی کارگاهی، عملیات بندری، طراحی و چیدمان فضایی و radiosurgery.

در پرتودرمانی با CyberKnife هدف سوزاندن تومور بدون آسیب به بافت سالم است: دوز تومور در بازه (مثلاً ۲۰۰۰ تا ۲۲۰۰) و دوز ساختارهای حساس زیر حد (مثلاً ۵۰۰) باید باشد که مجموعه‌ای از نامعادله‌های خطی روی شدت پرتوها می‌شود.

مثال دیگر: edge labeling (والتز، ۱۹۷۵) برچسب‌گذاری یال‌های تصویر اجسام چندوجهی به‌صورت محدب (+)، مقعر (−) یا پوششی؛ هر رأس یک متغیر با دامنه مجموعه برچسب‌های مجاز نوع رأس است و قید می‌گوید دو رأس مجاور باید برچسب یال مشترک را یکسان بدهند، و AC3 روی آن اعمال می‌شود.
