01

Best-First و تابع ارزیابی

تابع ارزیابی f(N) ≥ 0 هر گره را به یک عدد نگاشت می‌کند (هرچه کوچک‌تر، امیدبخش‌تر) و Best-First صف Fringe را به ترتیب صعودی f مرتب می‌کند. «Best» به کیفیت مسیر اشاره ندارد و Best-First در حالت کلی بهینه نیست.

  • f(N) = g(N) + h(N): تخمین هزینه راه‌حل از میان N
  • f(N) = h(N): Greedy Best-First
02

تابع هیوریستیک

h(N) هزینه رسیدن از STATE(N) تا هدف را تخمین می‌زند و فقط به حالت (و آزمون هدف) بستگی دارد. برای ۸-پازل:

هیوریستیکتعریفقابل‌قبول؟
h1تعداد کاشی‌های جابه‌جابله
h2مجموع فاصله Manhattan کاشی‌ها تا جایگاه هدفبله
h3مجموع وارونگی‌های جایگشتخیر

در ناوبری ربات: فاصله اقلیدسی (L2) و فاصله منهتن (L1). Greedy ممکن است در مینیمم محلی گیر کند و در حالت کلی نه کامل است و نه بهینه.

03

هیوریستیک قابل‌قبول

اگر h*(N) هزینه واقعی مسیر بهینه از N تا هدف باشد، h قابل‌قبول (admissible) است وقتی:

تعریف

0 ≤ h(N) ≤ h*(N) برای هر گره؛ یعنی هیوریستیک همیشه خوش‌بین است. برای گره هدف h(G) = 0.

روش ساخت: هزینه راه‌حل بهینه یک مسئله آسان‌شده (relaxed) با حذف برخی قیدها. مثلاً فاصله منهتن یعنی حذف مانع‌ها و فاصله اقلیدسی یعنی حذف مانع‌ها و قید حرکت روی شبکه.

04

الگوریتم A*

A* همان Best-First با f(N) = g(N) + h(N) است که h قابل‌قبول و هزینه یال‌ها ≥ ε > 0 است.

نتیجه ۱

A* کامل و بهینه است (وقتی گره‌های تکراری حذف نشوند).

  1. پایان‌پذیری اگر راه‌حلی وجود دارد، چون f(N) ≥ g(N) ≥ d(N)·ε، گره‌ای روی مسیر راه‌حل در Fringe می‌ماند و نهایتاً گسترش می‌یابد.
  2. بهینگی فرض کنید C* هزینه بهینه و G' هدف غیربهینه در Fringe باشد: f(G') = g(G') > C*، اما گره‌ای K روی مسیر بهینه دارد f(K) ≤ C*؛ پس G' هرگز زودتر گسترش نمی‌یابد.
محدودیت

A* ممکن است حافظه نمایی بخواهد. برای مسئله بی‌راه‌حل با فضای نامتناهی هرگز تمام نمی‌شود؛ در عمل باید محدودیت زمانی تعیین کرد.

05

هیوریستیک سازگار

هیوریستیک h سازگار (consistent یا monotone) است اگر برای هر گره N و فرزندش N':

نامساوی مثلثی

h(N) ≤ c(N, N') + h(N') و h(G) = 0

  • هر هیوریستیک سازگار، قابل‌قبول هم هست؛ عکس آن لازم نیست درست باشد
  • f در طول هر مسیر غیرنزولی است
  • نتیجه ۲: اگر h سازگار باشد، هر وقت A* گرهی را گسترش می‌دهد، مسیر بهینه به حالت آن را پیدا کرده است

بنابراین با CLOSED می‌توان حالت‌های گسترش‌یافته را ثبت و گره‌های تکراری را حذف کرد. h ≡ 0 سازگار است و A* با آن همان UCS می‌شود (BFS و UCS حالت‌های خاص A* هستند). h1 و h2 در ۸-پازل سازگارند؛ فاصله اقلیدسی هم سازگار است.

06

دقت هیوریستیک و ضریب انشعاب مؤثر

اگر h1(N) ≤ h2(N) برای همه گره‌ها، h2 دقیق‌تر (آگاه‌تر) است.

نتیجه ۳

A* با h2 هر گره‌ای را که A* با h1 لازم نمی‌دارد گسترش نمی‌دهد (به‌جز بعضی گره‌ها با f = C*).

ضریب انشعاب مؤثر b* از رابطه n = 1 + b* + (b*)² + … + (b*)^d به دست می‌آید (n تعداد گره‌های گسترش‌یافته و d عمق راه‌حل).

07

ساخت هیوریستیک خوب

  • با حل مسئله آسان‌شده در هر گره؛ مثلاً h2 معادل حل ۸ مسئله ساده است که برهم‌کنش منفی کاشی‌ها را نادیده می‌گیرد
  • Pattern database: h = d1234 + d5678، با پیش‌محاسبه و ذخیره فاصله‌ها؛ برای ۱۵ و ۲۴-پازل چند مرتبه سرعت می‌دهد
نکته عملی

اگر نتوان هیوریستیک دقیق و سازگار ساخت، گاهی هیوریستیک غیرقابل‌قبولی که در عمل خوب کار می‌کند بهتر است، هرچند کامل بودن و بهینگی دیگر تضمین نمی‌شود.

09

جستجوی محلی

جستجوی محلی فقط حالت فعلی را نگه می‌دارد (بدون درخت)؛ برای مسائلی مناسب است که مسیر مهم نیست (مثل ۸-وزیر) و شباهت زیادی به بهینه‌سازی دارد.

Pseudocode — Steepest Descent 
S <- initial state
Repeat:
    S' <- argmin h(S') over S' in SUCCESSORS(S)
    if GOAL?(S') return S'
    if h(S') < h(S) then S <- S' else return failure
  • مشکل: گیر افتادن در مینیمم محلی؛ راه‌حل‌ها: random restart و Monte Carlo descent
  • Min-conflicts در ۸-وزیر: یک وزیر مورد حمله را در ستونش به خانه‌ای با کمترین تعداد حمله ببرید؛ چون جواب‌ها زیاد و خوب پخش‌شده‌اند، زمان تقریباً به تعداد وزیرها بستگی ندارد
  • Simulated annealing: حرکت بدتر با احتمال exp(−Δh/T) پذیرفته می‌شود و دمای T به‌تدریج کم می‌شود
  • جستجوی محلی موازی: Beam search و الگوریتم ژنتیک
